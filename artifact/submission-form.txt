Artifact description
This source artifact evaluates ERA, BaseFold-code, Brakedown, and EA encoders
under a common Fiat-Shamir interleaved evaluation argument. It also compares
a corrected, optimized ERA codeswitching IOPP against a local recursive
BaseFold implementation. The artifact contains exact serialized proof-size
measurements, commitment/proving/verification timings, numerical distance
calculations, tests, fixed parameter files, and a pinned Docker build recipe.
The README maps each component to the supplied paper and explicitly records
deviations. Table 3's original configuration is supported; the additional
2^28 AWS results and corrected implementation are identified separately.
The older analytical estimates in Table 4/Figure 7 are not claimed as reproduced
by the current measured wire format. This is an encoder/IOPP artifact, not a
complete zero-knowledge SNARK implementation.
